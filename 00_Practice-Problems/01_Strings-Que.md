# 🐍 Python – Strings Practice Questions

## Easy

**Q1.** Write a program that takes a string input from the user and prints its length.

**Q2.** Take a string and print it in uppercase and lowercase.

**Q3.** Write a program to check if a given string starts with `"Hello"`.

**Q4.** Take a sentence as input and count how many words are in it. *(Hint: use `.split()`)*

**Q5.** Write a program to replace all spaces in a string with underscores (`_`).

**Q6.** Take a string and print it in reverse order.

**Q7.** Write a program to check whether a given string is a palindrome or not.
*(Example: `"racecar"` → Yes, `"hello"` → No)*

**Q8.** Count the number of vowels (`a, e, i, o, u`) in a given string.

**Q9.** Write a program that removes all leading and trailing whitespace from a string.

**Q10.** Extract only the first 5 characters from a given string using slicing.

---

## Intermediate

**Q11.** Write a program to find and print all the positions (indices) of a given character in a string.
*(Example: in `"banana"`, character `"a"` appears at index 1, 3, 5)*

**Q12.** Take a sentence and capitalize the first letter of every word.
*(Without using `.title()` directly — implement the logic manually)*

**Q13.** Write a program that checks whether two strings are anagrams of each other.
*(Example: `"listen"` and `"silent"` → Yes)*

**Q14.** Given a string, remove all duplicate characters and print the result while maintaining original order.
*(Example: `"programming"` → `"progamin"`)*

**Q15.** Write a program to count the frequency of each character in a string and display it.

**Q16.** Take a string and compress it using run-length encoding.
*(Example: `"aaabbc"` → `"a3b2c1"`)*

**Q17.** Write a program to check if a string contains only digits, only letters, or a mix of both.

**Q18.** Given a string, find the longest word in it.

---

## Hard

**Q19.** Write a program to find all permutations of a given string.
*(Example: `"abc"` → `"abc"`, `"acb"`, `"bac"`, `"bca"`, `"cab"`, `"cba"`)*

**Q20.** Given two strings `s1` and `s2`, find the longest common substring between them.
*(Example: `s1 = "abcdef"`, `s2 = "zbcdf"` → `"bcd"`)*
